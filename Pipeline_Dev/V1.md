## Current NCBI Data Collection Pipeline

The current workflow is **year-stratified** and **source-stratified**. Each annual window is analyzed independently so that changes in serovar composition can be compared over time.

### Workflow

1. Select **Organism Group = *Salmonella enterica***.
2. Restrict **Location = USA**.
3. Apply one annual collection-date window at a time:
   - 2016–2017
   - 2017–2018
   - 2018–2019
   - ...
   - 2024–2025
4. Apply poultry/chicken **Host** terms, including *Gallus gallus* and relevant submitter-entered variants.
5. Classify **Isolation Source** terms into `PREHARVEST` or `POSTHARVEST` according to the project source dictionary.
6. Within each source group, select serovar entries one at a time and record the **cumulative matched-isolate count**.

 -reward 1 -penalty -5 -gapopen 3 -gapextend 3 -dust yes -soft_masking true –evalue 700 -searchsp 1750000000000 -outfmt 6.
